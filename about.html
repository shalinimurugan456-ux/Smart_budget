Zero Server Overkill

100% Client-Side Architecture

Unlike bloated web applications that require complex Node.js runtimes, databases, and heavy server infrastructure, PocketSmart AI is engineered with HTML5, CSS3, ES6+ Vanilla JavaScript, and JSON.

This design guarantees instant page load speeds, zero downtime vulnerabilities, full offline resilience, and effortless single-click deployment to GitHub Pages.

Zero backend runtime or build steps required
Full GitHub Pages compatibility with relative path resolution
Persistent local state for plans, wishlist, and admin CRUD via localStorage

Got Questions?

Frequently Asked Questions

Is this platform completely free to use?

Yes. PocketSmart AI is a client-side frontend platform. All budget planning, recommendation generation, history storage, and wishlist management functions without paywalls.

How does authentication work without a backend?

Authentication is handled as a frontend demo using browser localStorage. You can log in using the demo credentials admin / 12345 or create a custom demo user on the register page.

How can I deploy this website to GitHub Pages?

Because all assets, stylesheets, scripts, and JSON data use relative file paths, you simply upload this folder to a GitHub repository, open Settings > Pages, and select the Main branch. It deploys in seconds.
